# 🛒 Online Retail Sales Analysis using SQL

## 📌 Project Overview

In this project, I worked on analyzing an online retail sales dataset using SQL.  
The goal of this project was to practice real-world SQL data cleaning and business analysis techniques while improving my analytical thinking skills.

I used SQL Server to clean the raw dataset, create a cleaned working table, and perform different types of sales, customer, product, and country-wise analysis.

---

## 🛠️ Tools Used

- SQL Server Management Studio (SSMS)
- SQL

---

## 📂 Dataset Information

The dataset contains online retail transaction data including:
- Invoice details
- Product information
- Customer IDs
- Country information
- Quantity purchased
- Unit prices
- Transaction dates

---

## 🧹 Data Cleaning Performed

Before analysis, I cleaned the dataset by:
- handling missing customer IDs
- removing invalid quantity and unit price values
- converting datetime into proper date format
- creating a cleaned working table
- creating a revenue column for analysis

---

## 📊 Analysis Performed

### KPI Analysis
- Total Revenue
- Total Customers
- Average Transaction Value

### Sales Trend Analysis
- Monthly Revenue Trends

### Product Analysis
- Top Products by Revenue
- Most Frequently Ordered Products

### Customer Analysis
- Top Customers by Spending
- Repeat Customers
- Customer Segmentation

### Country Analysis
- Top Countries by Revenue
- Revenue Contribution Percentage

### Advanced SQL Analysis
- Monthly Growth Analysis using Window Functions

## 📈 Key Insights

- A small number of customers contributed significantly to total revenue.
- Certain products generated high sales volume as well as high revenue.
- Revenue trends varied across months, indicating seasonal purchasing behavior.
- Some countries contributed a major share of total sales revenue.
